# Grand Line

A pirate-life management/adventure game set in a One Piece-inspired world.

## Play
Download **`play/GrandLine.html`** and double-click it. It runs in any modern browser,
with no install needed. Progress saves automatically in your browser; use **Export save** to back it up.

## Found a bug?
Tell Claude: what you did, what happened, what you expected, plus a screenshot.
If a red error box appears, screenshot it. Exporting your save helps too.

## For development
```
npm install
npm run check   # typecheck, tests, build, browser smoke test
```
Docs: `docs/DESIGN.md` (what the game is), `docs/ROADMAP.md` (plan),
`docs/HANDOFF.md` (current state), `CHANGELOG.md`.
